## Фронтенд

### Запуск

Требуется Node.js и npm. В корне проекта выполните:

```bash
npm install
npm run dev
```

Для production-сборки используйте `npm run build`.

### Страницы и управление

- **Лента** (`/composers-feed`) показывает одного композитора: видео, частотности интервалов, имя, описание и число отметок «Нравится». Кнопка с сердцем переключает отметку, кнопка со стрелкой открывает следующую карточку. Если описание длиннее двух строк, его можно развернуть и свернуть.
- **Плитка** (`/composers-grid`) показывает список карточек. Два ползунка задают нижнюю и верхнюю границы фильтра по частотности 1; кнопка **«Применить»** обновляет список. Кнопка **«Удалить»** убирает карточку из текущего отображения. Нажатие на карточку открывает соответствующего композитора в ленте.
- Нижняя панель содержит пункты **«Лента»**, **«Добавление»**, **«Плитка»** и **«Вход»**. Доступны переходы на ленту и плитку; добавление и вход отключены.

### Данные и медиа

Карточки хранятся в `src/data/composers.ts` в локальном массиве `COMPOSERS_MOCK`. Данные загружаются без backend и HTTP-запросов к API. Для отсутствующего изображения используется `default_cover.jpg`, для отсутствующего видео — `default_video.mp4`.

Интерфейс реализован на React, TypeScript, Vite и React-Bootstrap. Состояние лайков, фильтра, раскрытия описания и удаления карточек хранится в локальном состоянии React; Redux и React Context не используются.
